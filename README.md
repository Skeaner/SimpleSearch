# 极简划词搜索 Mod (SimpleSearch)

[![一键安装](https://img.shields.io/badge/点击安装-Tampermonkey-brightgreen.svg)](https://github.com/Skeaner/SimpleSearch/raw/refs/heads/master/Simple.user.js)

一个轻量级篡改猴（Tampermonkey）划词搜索脚本。保留小巧悬浮工具栏、关键词高亮与自定义引擎配置，精简掉了拖拽搜索、拖拽打开链接与图片保存等冗余功能，并内置常用中文搜索引擎与 Base64 图标。

## 主要功能

- **划词悬浮工具栏**：选中文本后弹出工具栏，支持一键复制与多引擎搜索；选中内容为网址或域名时，自动在最左侧显示「打开」按钮。
- **关键词增量高亮**：内置 6 组高亮配色，点击「高亮」可为当前选中词添加页面内增量高亮并监听动态内容；支持全局开启/关闭高亮功能。
- **独立设置面板（Shadow DOM）**：点击工具栏右侧齿轮图标即可打开设置面板，样式与宿主页面隔离：
  - 自由勾选需要显示的内置搜索引擎
  - 开关引擎图标显示（关闭后工具栏更紧凑）
  - 调整「复制」与「高亮」按钮的先后顺序
  - 添加、勾选或删除自定义搜索引擎（使用 `%s` 作为关键词占位符）
- **跨站配置同步**：通过 `GM_setValue` / `GM_getValue` 持久化保存配置，跨网站生效。

## 内置搜索引擎

| 名称 | 用途 | 名称 | 用途 |
| :--- | :--- | :--- | :--- |
| **G** | Google 搜索 | **小红书** | 小红书搜索 |
| **百度** | 百度网页搜索 | **抖音** | 抖音搜索 |
| **百科** | 百度百科词条 | **京东码** | 京东商品编码直达 |
| **维基** | 中文维基百科 | **京东搜** | 京东关键字搜索 |
| **豆瓣** | 豆瓣搜索 | **高德地图** | 高德地图地点搜索 |
| **翻译** | 百度翻译 | **百度地图** | 百度地图地点搜索 |

> 如需更换或扩展图标，可直接修改 [Simple.user.js](Simple.user.js) 顶部的 `ENGINE_ICONS`（支持填入 Base64，同品牌引擎可自动复用）。

## 安装方法

1. 在浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/)（或 ScriptCat / Violentmonkey 等用户脚本管理器）。
2. 点击上方 **点击安装** 徽章，或在脚本管理器中导入仓库内的 [`Simple.user.js`](Simple.user.js)。
3. 安装后在任意网页划选文字即可弹出工具栏。
